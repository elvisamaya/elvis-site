Digital Hardware & Architecture

Pipelined RISC-V Processor

I built single-cycle and five-stage RV32I cores in Verilog to compare how pipeline hazards affect performance. The pipelined core forwards ALU results, stalls on load-use dependencies, and flushes younger instructions on taken branches.

28% lower simulated CPI with forwarding on the included workloads (1.924 to 1.380). The testbench checks final registers, data memory, and retired instruction counts against a Python reference model.

Digital Design RTL

I designed and verified a set of synthesizable Verilog blocks, including a UART, SPI master, and synchronous FIFO. The UART echo top connects the receiver, FIFO, and transmitter into one serial datapath.

Six self-checking testbenches cover cases such as randomized FIFO traffic, UART framing errors, SPI edge timing, and end-to-end echo. CI runs Icarus Verilog simulations and Verilator lint.

Embedded Systems & Signal Processing

Vital Sign Monitoring with mmWave Radar

A contactless heart rate and respiration monitoring system built with a 77 GHz FMCW mmWave radar (TI IWR6843ISK). Instead of wearable or contact sensors like PPG, it measures sub-millimeter chest displacement from the phase of the radar signal.

I derived and implemented the full signal processing pipeline (range-FFT, DC offset correction, phase extraction and unwrapping, and slow-time FFT) and designed the chirp parameters to reach under 0.1 Hz frequency resolution, enough to separate breathing (0.2–0.5 Hz) from heart rate (1–1.6 Hz). Across multiple trials, the system reliably detected respiratory rate (14–19 bpm) and heart rate (61–80 bpm) from 1 m away. Stanford University, May–June 2026.

RTOS Task Scheduler

A multitasking embedded firmware system built on an STM32 Nucleo board using FreeRTOS. The system runs concurrent tasks for sensor polling, motor control, status LEDs, and a UART command shell — all coordinated through task priorities, preemption, queue-based messaging, and mutex-protected output.

Commands like motor open, led on, and status can be issued live over serial. Hardware includes the STM32 NUCLEO-F446RE, an SG90 servo, and an external 5V supply. Firmware written in C.

Butter Bot

An autonomous mini forklift inspired by the Butter Robot from Rick and Morty. The robot uses a camera to find a stick of butter, slides its forks under a small pallet, lifts it, and delivers it to a red drop-off marker.

An STM32 Nucleo-L4R5ZI-P runs the robot as an interrupt-driven state machine. It receives butter and marker positions from a XIAO ESP32S3 Sense camera over UART, reads heading from an LSM303AGR magnetometer over I2C, and drives two DC gearmotors and an SG92R servo with timer PWM. The 25-part 3D-printed body includes a parallel-link forklift that lifts the forks 30 mm while keeping them level. In progress, Fall 2026.
